# 尚未裝訂。

> 人生是一本還未裝訂的書籍，而我仍在編輯。

收錄散落於不同年歲裡的文字與影像。  
關於青春、告別、失去、選擇，以及那些仍在成為的自己。

**WORDS · MEMORIES · BECOMING**

---

## About

《尚未裝訂。》是一座屬於 Violet 的私人文學檔案館。

這裡保存不同時期寫下的文字、照片與記憶。  
有些故事已經結束，有些仍在發生，而有些自己，仍在成為...

網站以文字為主要媒介，影像則作為記憶的載體。  
比起先替人生下定論，我更想保留那些仍可以被重新閱讀、重新理解的頁面。

---

## Concept

**尚未裝訂，不代表尚未寫下。**

許多頁面早已存在，只是仍可以被增添、重排與重新理解。

因此，這個網站既是一份作品收藏，
也是一個持續編輯中的個人檔案。

---

## Creation

The concept, structure, writing, photography, and visual direction of this website are curated by Violet.

This project was created as a personal literary archive, transforming scattered words and memories into a digital space of my own.
